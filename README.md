# Práctica de Python – Analista de Datos

## Descripción
Este proyecto contiene ejercicios básicos de Python orientados al análisis de datos.

## Objetivos
- Practicar variables y tipos de datos.
- Utilizar listas, bucles y condicionales.
- Trabajar con diccionarios.
- Crear funciones para calcular estadísticas básicas.

## Tecnologías
- Python 3
- Google Colab o Jupyter Notebook

## Contenido
El archivo `practica_python.ipynb` contiene la resolución de las cuatro tareas propuestas.
